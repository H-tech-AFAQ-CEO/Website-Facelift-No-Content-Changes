# Palm Beach Shutters & Shades — Luxury Window Treatments

**Palm Beach Shutters & Shades** is a premium, single-page HTML/CSS/JS website designed for a high-end window treatment company serving Palm Beach County. The site combines elegant typography, smooth animations, and a sophisticated color palette to showcase custom shutters, shades, blinds, and drapes.

## ✨ Features

### Design & Aesthetics
- **Elegant Color Palette** – Warm sands, creams, driftwood tones, and deep ink with a signature palm green accent.
- **Custom Cursor** – Interactive cursor with ring that scales on hover for a tactile, luxury feel.
- **Smooth Scroll Reveal** – Content animates into view as users scroll using Intersection Observer.
- **GSAP-style Transitions** – CSS-based fade-up, fade-right, and scale animations throughout.

### Core Sections
| Section | Description |
|---------|-------------|
| **Hero** | Full-screen split layout with tagline, headline, CTA buttons, and floating years-of-excellence badge. |
| **Marquee Strip** | Infinite scrolling product categories to reinforce brand offerings. |
| **Services/Products** | Grid of six service cards (Plantation Shutters, Roller Shades, Roman Shades, Blinds, Drapes, Motorization) with hover effects. |
| **Feature Split** | "Why Choose Us" section with in-home consultation benefits and checkmark list. |
| **Stats Band** | Animated counters for Years in Business, Homes Transformed, Product Options, and Rating. |
| **Gallery** | Responsive masonry-style grid showcasing recent installations with image overlays. |
| **Process** | Five-step workflow (Consultation → Measurement → Fabrication → Installation → Lifetime Support). |
| **Testimonials** | Client reviews with star ratings, author names, and locations. |
| **Contact** | Split layout with contact info and a consultation request form. |
| **Footer** | Multi-column footer with brand info, product links, company links, and contact details. |

### Interactive Elements
- **Sticky Navigation** – Navbar becomes translucent on scroll with backdrop blur.
- **Mobile Hamburger Menu** – Full-screen drawer navigation for tablet and mobile devices.
- **Hover Effects** – Service cards, gallery images, and testimonial cards all feature subtle scale/color transitions.
- **Form Inputs** – Styled fields with focus states and border highlighting.

### Typography
- **Display Font:** `Cormorant Garamond` – Elegant, serif for headings and brand identity.
- **Body Font:** `DM Sans` – Clean, modern sans-serif for readability.
- **Letter Spacing:** Uppercase navigation, section tags, and CTA buttons use generous tracking.

### Performance & Responsiveness
- Fully responsive grid layouts that adapt from desktop to mobile.
- CSS Grid and Flexbox for flexible, modern layouts.
- Optimized images via Unsplash with `object-fit: cover` for consistent aspect ratios.
- Touch-friendly interactions with no custom cursor on mobile devices.
